WHAT WE BUILD

기관 전용 고난도 문항 생성·검증 시스템

귀사가 과목, 단원, 난이도, 문항 유형과 필수 사고 구조를 지정하면 문항의 수학적 구조를 먼저 설계하고, 이를 실현하는 함수와 조건을 탐색합니다. 생성 결과는 별도의 독립 풀이로 다시 검토하며 조건·모델·버전·수정·채택·폐기 이력을 프로젝트별로 관리합니다.

01

기관 기준에 따른 반복 생산

단원·난이도·문항 유형·논리 구조를 기준으로 여러 후보를 반복 생성하고 비교합니다.

02

검수 근거가 남는 품질관리

독립 풀이, 조건 사용, 경우·경계, 복수정답, 우회 풀이와 유사성 검토 결과를 함께 제시합니다.

03

기관 업무에 맞춘 운영 구조

전용 웹, 로컬 모델, 전용 클라우드, 온프레미스·폐쇄망과 권한·로그·버전 관리를 지원합니다.

02 IDENTITY & HISTORY

미션·비전·관계

높은 난도의 문항을 빠르게 많이 만드는 것보다, 교육기관이 실제로 사용할 수 있는 정확하고 관리 가능한 출제 시스템을 구축하는 데 집중합니다.

MISSION

더 정교하고 안정적인 기술 기반

고난도 문항 연구·제작 업무를 구조 설계부터 생성·검증·수정 이력 관리까지 연결합니다.

VISION

신뢰하고 장기간 사용할 수 있는 평가 인프라

수능 수학에서 기술성과 활용성을 증명한 뒤 수능 전 과목, LEET와 전문시험으로 확장합니다.

RELATIONSHIP

07 BUSINESS & DELIVERY

도입 방식

기술과 실제 결과물을 먼저 확인한 뒤 사용 목적과 보안환경에 맞는 범위로 확장합니다.

OPTION 1

맞춤형 PoC

기관이 지정한 과목·단원·난이도·문항 유형과 사고 구조로 실제 결과와 업무 적합성을 검토합니다.

  • 기관 지정 조건 기반 문항 생성
  • 정답·해설·독립 풀이 제공
  • 연구진 검토와 수정 반영
  • 정식 도입 범위 정의
OPTION 2

귀사 전용 웹

연구진이 출제 조건을 직접 설정하고 생성 문항과 검토 결과를 프로젝트별로 관리합니다.

  • 전용 접속환경과 권한 분리
  • 문항 DB와 버전·승인 이력
  • 기관 문체·난이도·검수 기준 반영
  • 사용자 교육과 유지관리
OPTION 3

온프레미스·폐쇄망

문항과 출제 데이터가 외부로 전달되지 않도록 기관 서버 또는 폐쇄된 내부환경에 구축합니다.

  • 로컬·기관 전용 모델 구성
  • 내부 인증과 접근통제
  • 저장·반출·다운로드 기록 관리
  • 백업·복구와 운영 안정화

도입 절차: 비공개 시연 → NDA → 기관 지정 조건 기반 PoC → 전용 시스템 구축 → 기관 라이선스 → 유지·고도화 → 과목·시험 확장
